# Reproduction archive: When to Call a Time-Series Foundation Model

Archive for the NeurIPS 2026 TS-LIMITS workshop paper. Everything a table or
figure in the paper reads is here as an evaluation quantity. Repository paths,
host names and scheduler identifiers have been removed; the licences are in
`LICENSE-DATA` and `LICENSE-CODE`. Requests for anything not released go to
the corresponding author named in the paper.

## What is in it

- `records/fm/`: one file per (arm, country). Columns `cc, test_year, horizon,
  origin_ts, target_ts, ape` (plus `cap, passes` for the rollout arms). `ape` is
  the absolute percentage error of the q50 forecast at the target hour. Raw load
  values and forecasts are not redistributed: a forecast beside an APE reveals
  the load value, and the load provider's redistribution terms are not stated on
  its data page. They can be regenerated by users with access to the source
  data, or shared only where the provider's terms permit.
- `records/structural/`: the frozen structural model on the same grids, columns
  `country, test_year, horizon, anchor_t, target_t, ape` plus the 22 request-time
  gate features (calendar, holiday flags, climatology, rolling statistics of the
  anchor window). `per_origin_seasonal_naive_2025.parquet` is the weekly-persistence baseline
  (the load $168\lceil h/168\rceil$ hours before the target).
- `records/served/`: per-request served losses of every policy in Table 1 and
  its controls, with the deployed gate's score (`served_per_request.parquet`;
  `_shallow`, `_ridge` for the alternative learners; `_native` for the
  capability-matched family where present).
- `gates/`: the eight deployed margin regressors (`HistGradientBoostingRegressor`,
  scikit-learn 1.5.2 defaults, 300 iterations, seed 0), refit deterministically
  from the development records and pickled; `features.json` names the 22
  features; `thresholds.csv` holds the 2024-frozen budgets and score thresholds
  under both metrics.
- `results/`: every CSV and JSON the tables read. The per-request records carry
  absolute percentage errors only, so the load-weighted MAPE and megawatt MAE
  columns (`tab_estimands`, `tail_robustness.csv`, the `wmape_*` columns of
  `baselines.csv`) cannot be recomputed from `records/`; they are regenerated from
  the persisted result files here, which is also how the paper reads them.
- `tables/`: the `tab_*.tex` files exactly as the paper inputs them.
- `scripts/`: the analysis scripts, with the authors' repository path and host
  names rewritten. Each writes the CSVs and `tab_*.tex` it owns;
  `tslimits_tables.py` writes the main tables from the CSVs.
- `MANIFEST-tables.md`: one exact command per table and figure, and whether it
  rests on the released per-request records or on persisted aggregate files.
- `MANIFEST.txt` and `MANIFEST.sha256`: every file with its size and digest.
- `LICENSE-DATA` (CC BY 4.0: `records/`, `results/`, `tables/`) and
  `LICENSE-CODE` (MIT: `scripts/`, `gates/`).

## Versions and hosts

- Chronos-2: `amazon/chronos-2` revision `0f8a4404`; chronos-forecasting 2.2.2,
  transformers 4.57.6, huggingface-hub 0.36.2, torch 2.9.1+cu128, CUDA 12.8,
  driver 580.159.04, NVIDIA H200 (power limit 700 W).
- TimesFM-2.5: `google/timesfm-2.5-200m-pytorch` revision `1d952420`; timesfm
  from `google-research/timesfm` at commit `d720daa6`, numpy 2.3.5, torch 2.9.1,
  pandas 2.3.3, installed per job.
- Gate and analysis: Python 3.11.14, scikit-learn 1.5.2, numpy 1.26.4, pandas 2.x.
- Gate latency: AMD EPYC 9454, one thread (`OMP_NUM_THREADS=1`). FM latency and
  energy: the H200 node. Structural latency: carried over from its own
  measurement. Three hosts; the paper says so.
